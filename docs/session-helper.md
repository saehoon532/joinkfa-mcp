# JOIN KFA 세션 연결 도우미

`tools/capture_kfa_session.py`는 운영자가 직접 실행하는 로컬 도우미입니다.
Render 서버가 실행하는 코드가 아니며 MCP 도구로 공개하지 않습니다.

1. Python 환경에 `playwright`를 설치하고 Chrome을 준비합니다.
2. `.secrets` 폴더를 만들고 현재 사용자만 읽고 쓸 수 있도록 권한을 설정합니다.
3. `python tools/capture_kfa_session.py`를 실행합니다.
4. 새 Chrome 창에서 직접 로그인하고 경기 상세를 하나 엽니다.
5. 도우미는 해당 경기 요청의 식별자와 JOIN KFA 도메인 쿠키만 처리합니다.
   로그인 POST 본문은 읽지 않고, 비밀번호·HAR·전체 브라우저 프로필을 저장하지 않습니다.
6. 이름 엄세훈과 실제 경기 상세 HTTP 조회가 모두 검증되면
   `.secrets/kfa-session.json`을 저장하고 임시 Chrome 창을 닫습니다.
7. 이 파일을 해당 계정 세션을 사용할 권한이 있는 Render 서비스의
   Secret File `kfa-session.json`에 설정합니다. 내용을 채팅이나 Git에 넣지 마세요.

유효 기간은 최대 4시간이며 쿠키의 명시된 만료가 더 빠르면 그 시간을 적용합니다.
원본 사이트가 먼저 세션을 만료하면 즉시 다시 로그인해야 합니다. 기존 파일을
자동으로 덮어쓰지 않습니다. 사용자 이름이 다르면 저장하지 않습니다.

세션을 Render에 저장하면 서버와 호스팅 운영 환경이 해당 계정으로 접근할 수
있으므로 업로드 직전에 그 대상과 권한 이전을 확인합니다. 업로드 후 서버에서
`referee_auth_status`로 검증해야 연결 완료입니다. 로컬 검증만으로 서버 연결이
성공했다고 보고하지 않습니다.
